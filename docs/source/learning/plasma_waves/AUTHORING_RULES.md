# 等离子体波教学模块制作规则

确认日期：2026-11-19。

适用于 AlgoPlasma 等离子体波教学模块的新增课程与既有课程修订。07 课《第一条色散关系怎样推出来？》作为当前参考实现。这份说明面向课程作者和维护者，保存在作者文档中；教学正文面向学习者。

以下为确认采用的 18 条规则，已重新连续编号。

1. **始终面向读者。** 正文写给学习等离子体波的读者，不放给作者的解释、开发安排或后续制作建议。

2. **由浅入深，内容相对独立。** 每课围绕一个明确主题，在已有知识上继续建立内容，方便以后增加独立课程或页面。

3. **避免突然引入未讲过的概念。** 当前推导不需要的术语先不出现；确实需要的新概念，应先解释再使用。不要突然插入尚未讲解的知识，打断读者的思路。

4. **一课可以包含多张 PPT 页面。** 不把整课内容尽量塞进一张页面。新页面起始保持干净，通过点击逐步展开。

5. **有空间就补充，内容长再分组。** 同一页下方还有足够空间时，保留已有内容，点击后继续添加；较长推导再采用分组替换或分页。

6. **只让变化的内容出现动画。** 不变的标题、文字和图保持静止；只让新增或替换的部分缓慢浮现，避免整页闪动。

7. **全部文字都要便于远距离阅读。** 正文、单位、图注、补充说明都要足够大，字重不能太细，颜色不能太灰。放进括号的说明也不能缩成小字。

8. **公式排版优先考虑阅读。** 重要公式居中、单独成行，文字解释与公式分开，不把长公式挤在大段文字中。

9. **核心推导交代中间步骤。** 明确说明从哪个公式出发、代入什么、怎样展开和化简，避免直接跳到结果。

10. **物理量要给单位。** 引入概念、符号和数值时，同时说明含义及单位。

11. **多用动画辅助理解。** 用与概念和公式对应的动画呈现变化过程和关系，帮助读者理解所讲内容。

12. **配合互动和思考题。** 可以加入参数调整、对照观察、预测和测试问题，帮助读者检查理解。

13. **按钮数量要克制。** 保持界面简洁，不一开始就摆满操作入口。

14. **推进讲解必须通过明确按钮。** 点击图、曲线或页面空白处，不应跳到下一步或下一页。

15. **提供两个不同的起始按钮。** “本页起始”回到当前幻灯片开头；“本课起始”回到整课开头。

16. **课程之间能够连续阅读。** 每课提供上一课、下一课链接，不要求读者每次返回目录。

17. **目录简短，避免反复展示长说明。** 索引只介绍每课是什么、讲什么；不要在多个页面重复放置同一个长展开标签。长讲解应放到对应的 PPT 步骤中。

18. **中英文同步制作。** 提供语言切换，内容修改同时更新两种语言。

07 当前采用的幻灯片数量、步骤数量、动画时长以及具体配色和字号数值，属于实现参数，不作为这份规则中的固定标准。
