反射入流为什么要迭代？

某个速度到达壁面后，反射会给另一个速度提供入流。若直接使用本轮尚未求出的反射方向，就形成循环依赖。因此整轮固定已完成轮次的壁面出射分布，内部单元仍使用本轮上游结果。
