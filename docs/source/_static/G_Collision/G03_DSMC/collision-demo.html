    模型假设与计算细节

    采用无外力飞行、2D3V、单位厚度和等权重 W = 1；x/y 外边界为镜面反射或吸收，z 周期。速度单位 v₀ = √(1 eV/mₑ)，时间单位 L₀/v₀。以电子质量为单位，中性质量 Mₐ = Mᵢ + 1，忽略结合能质量亏损。A* 表示原子的激发态。

    重粒子弹性核 q = σg = 0.12g（HS）或 0.12g2−2ω（VHS/VSS），参考速率为 1。HS/VHS 各向同性；VSS 用 cosχ = 2R1/α−1。黏度标度为 η(T)/η(Tref) = (T/Tref)ω，ω 为温度指数。本实验固定参考核；拟合实验黏度还需随 α 联合标定。

    固定相对能量实验令 μᵣ = m₁m₂/(m₁+m₂)、Erel = μᵣg₀²/2，靶初始静止，入射粒子沿 +x 运动。每次恢复这组初态并抽一次散射，共 2000 次；样本以已发生碰撞为条件，不经过候选接受筛选。修改 ω 改变碰撞核，样本数量保持 2000。

    速率总体实验使用固定入射库：g 在 [0.25, 4]v₀ 均匀分布，靶静止，各碰撞事件独立地按 f_in(g)q(g) 抽样，f_in 是入射库的相对速率概率密度。速率与角度使用独立随机流，只改 ω 时可逐样本比较方向。这两个比较实验都不让入射库随碰撞弛豫。

    e–A 弹性核为 0.035g；基态激发核为 0.065g(1−11.55/Erel)，阈值 11.55 eV；电离核为 0.12g(1−Eth/Erel)3/2，基态 Eth = 15.76 eV，激发态 Eth = 4.21 eV。阈值以下为零。通道范围限于弹性、激发、单次电离、CEX 和下述屏蔽散射；截面采用教学参数，实际氩气预测需经验证的数据。

    单次电离用三体 Jacobi 坐标，余能份额按 Beta(3/2,3/2) 分配，两组相对方向各向同性，以共同末态保持守恒。该分配律是教学假设，实际次级电子能谱需另行建模。新电子与产物离子同位置，可参加当前子步剩余碰撞，从下一步开始飞行。基态 A–A⁺ 的 CEX 核为 0.1g，交换身份后按最终质量守恒重建速度。

    e–e、e–A⁺、A⁺–A⁺ 使用有限屏蔽教学核 Cg/(1+g²)²，C 分别为 0.3、0.4、0.2；角分布 p(cosχ) ∝ (1−cosχ+0.1)−2。这一模型用于展示配对与偏转；定量库仑输运需采用适用的库仑碰撞算子。

    电离改变成员数，候选用连续时间时钟：Λ = N(N−1)WM/(2V)，δτ = −ln(1−R)/Λ，选对后以 q/M 接受。每次结果后更新成员、上界与时钟，空候选也消耗时间。上界由胞元质心系动能和非负内部/电离能推得。运输分裂误差仍由物理步长控制，演示中的大步长用于观察事件。

    空间图的箭头标尺在重置时由总能量上界固定，不随单次碰撞自动改变。若勾选放大，重粒子统一乘 √(Mᵢ/mₑ)。前后对照图沿用这一物种倍率，但按本次事件统一局部放大：碰前后共用标尺，不跨事件比较箭头长度。虚线灰箭头表示碰前速度；速度只显示 x–y 投影，真实三维分量在状态表中。
