Validation Checklist
====================

.. rubric:: 修改前

记录修改对象、接口单位、需要保持的极限情况，以及预期会改变哪些计算结果。
只整理实现时，保留现有接口和数值约定；修改模型时，更新理论说明与测试预期，不能沿用旧图作为新模型结果。

.. rubric:: 从局部到应用

1. 用可手算的小数组检查公式、索引、四面符号和面积权重。
2. 检查非法输入的错误码、返回位置及输出是否可用。
3. 验证局部守恒、非负性或明确记录不满足条件的情况。
4. 将前处理输出接入 J03，检查共享面抵消、边界收支和源损项。
5. 瞬态扩展检查解析时间演化和时间步收敛，稳态扩展检查独立残差，不能只检查相邻步变化。
6. 最后运行完整应用并更新图像、参数和诊断量。

.. rubric:: 按扩展选择测试

.. list-table::
   :header-rows: 1

   * - 改动
     - 最小验证
     - 现有入口
   * - FM 入口或反射
     - 概率归一化、粒子率、单轨迹驻留与出射方向
     - :doc:`J01 Tests <J01_test_overview>`
   * - SN 求积、装配或边界
     - 解析积分、局部系统、壁面通量和部分入口积分
     - :doc:`J02 Tests <J02_test_overview>`
   * - 连续性闭合或时间推进
     - 共享面守恒、源损解析解、残差与时间阶
     - :doc:`J03 Tests <J03_test_overview>`
   * - 全链路物理模型
     - 统一物理条件的完整应用及独立诊断
     - :doc:`Application Tests </tests/012_fluid/application_tests>`

.. rubric:: 文档验收

侧栏条目必须对应独立页面，英文导航名保持稳定，正文可以用中文解释。
页内小节用于组织正文，不作为额外导航页。公式说明符号、单位、假设及源码位置，
测试页注明输入、被测接口、断言和执行命令。


.. rubric:: 当前测试能支持哪些结论

小测试记录注明验证时的源码与脚本指纹。完整应用按算例记录运行来源：
FM 已在近角点修复后复跑，SN 保留同日已完成的结果。
各层测试承担不同的验证任务：

.. list-table::
   :header-rows: 1
   :widths: 24 43 33

   * - 层级
     - 参考依据与已验证内容
     - 结论的范围
   * - J01 局部过程
     - 解析概率、指定轨迹、驻留时间与穿面计数；精确及近角点覆盖四种方向组合和两种到达顺序，概率测试使用三组固定种子
     - 验证采样和统计规则；不是大型密度场的统计置信区间
   * - J02 局部与组装
     - 面积分用独立三点 Gauss 积分；已知 3×3 解；反射收支；解析单束输运在 4/8/16 网格上的误差递减
     - 验证约化模型的离散实现；不能直接保证器件网格上的空间或速度精度
   * - J03 单步与瞬态
     - 源损解析解、双单元交换、时间加密及瞬态收支
     - 验证连续性推进；固定面系数闭合本身是模型假设
   * - 模块串联
     - 真实前处理通量接入 J03；从空场填充至参考平衡；检查局部和全域收支
     - 排查数据传递与符号错误；保持参考场不等于参考场没有离散误差
   * - 并行一致性
     - 串行、OpenMP、空间 MPI 与混合并行的场、通量和错误位置
     - 验证同机分区与线程结果；未验证多节点性能及网络差异
   * - 完整应用
     - FM B0、SN B0、SN ION 的非负性、收敛、局部残差和总粒子收支；从保存场重算诊断
     - 验证当前算例成功完成；不提供独立实验或解析真解

若要给大型算例的误差作定量结论，下一步应分别开展：

* 固定物理条件，加密 SN 空间网格、角方向和速率区间，并改变速度截断上限；
  每次只改变一类离散参数，记录密度与通量的变化。
* 对 FM 增加独立随机种子及历史数，报告密度、面通量的样本波动。
* 统计 SN 保正回退的位置与次数，检查结果是否被局部常数近似主导。
* 在多台机器上验证 MPI 通信，再测量强、弱扩展效率。

这些项目尚未完成，不能以现有 PASS 或前处理/J03 密度接近来替代。
