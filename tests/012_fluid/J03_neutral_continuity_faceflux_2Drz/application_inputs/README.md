# Application Inputs

[中文](README.zh-CN.md) | [English](README.en.md)

This directory supplies the nonuniform grid shared by the FM/SN → J03 applications.
B0 has no volume loss; ION uses a prescribed loss frequency. The FM application
currently implements B0 only. These files provide geometry; reference densities
and fluxes are generated by each preprocessing run.

## Files and format

| File | Content |
| --- | --- |
| `grid_r.dat` | Edges and widths of 256 radial cells, in metres |
| `grid_z.dat` | Edges and widths of 256 axial cells, in metres |
| [../application_case.f90](../application_case.f90) | Shared active-region and ION loss-frequency definitions |

Each grid file contains 256 data rows with four columns:

```text
cell_index  lower_edge_m  upper_edge_m  width_m
```

Indices start at 1. Adjacent edges must be continuous; each positive width must
equal the upper edge minus the lower edge. Radial coordinates must be nonnegative.
Blank lines and comment lines starting with `#` are ignored.

The active region uses Fortran one-based indices `(65:192,1:72)` and `(:,73:256)`,
giving 56320 active cells. Both preprocessors and both J03 drivers share this
index layout. Custom input directories must use the same filenames and preserve
the 256×256 grid and active-region indices.

## Prescribed loss frequency

The B0 volume-loss frequency is zero. ION evaluates this cosine window at active
cell centres:

```text
nu(r,z) = 1e5*cos(pi*(r-rmid)/(rmax-rmin))*cos(pi*(z-zmid)/(zmax-zmin)) [s^-1]
rmin = 0.013683098220475191 m
rmax = 0.024672244366128356 m
zmin = 0.0024709824265487373 m
zmax = 0.010022411397665104 m
rmid = (rmin+rmax)/2
zmid = (zmin+zmax)/2
```

The frequency is zero outside the window and in inactive cells. This definition
tests transport with prescribed loss. The function above generates the field
directly, without archived mask, density or ionization-field files.

## Input checks and application entries

Python 3's standard library is sufficient. From the repository root, run:

```bash
python3 tests/012_fluid/J03_neutral_continuity_faceflux_2Drz/validate_application_inputs.py tests/012_fluid/J03_neutral_continuity_faceflux_2Drz/application_inputs
```

Success prints `Application input grid: PASS`; missing files or invalid grid
formats return a nonzero status. Application scripts run the same check before
compilation.

Execution and output details are in the [FM application](../application_reference_J01/README.en.md)
and [SN application](../application_reference/README.en.md) guides.
