# J02 中性粒子 SN 输运测试

本目录验证离散纵标（SN）中性粒子输运模块。测试分为逐过程检查、模块内组装和并行一致性三层。

## 局部过程与组装

普通测试覆盖：

- 二维速度求积，以及 `midpoint` 与 `gauss-chebyshev` 两个名称对应相同离散点和权重；
- r-z 网格的柱坐标体积、面积和加权平均；
- 一阶不连续 Galerkin（P1-DG）体积分矩阵与面矩阵；面矩阵用独立三点 Gauss–Legendre 积分核对；
- 矩阵累加及已知解的 3×3 线性系统；
- 入口外侧气体的 Maxwell 分布、漂移 Maxwell 分布，入射粒子速度概率到分布函数的转换，以及指定通量归一化；
- 镜面方向映射、漫反射收支、部分面入口积分；
- 迎风扫描、反射迭代、局部保正和完整输运入口；
- 密度、平均速度、内部面及开放边界通量重构；
- 非法输入、尺度变化、失败方向与单元位置，以及失败后输出状态。

在仓库根目录运行：

```bash
bash tests/012_fluid/J02_neutral_sn_transport_2Drz/run.sh
```

该脚本运行 9 个程序，默认采用串行、八字节实数编译。
可用 `OPENMP=1 OMP_NUM_THREADS=4 OMP_DYNAMIC=FALSE` 启用线程。
`test_J02_transport_units.f90` 检查轴线几何、网格连接、损失矩阵、频率换算、
同一入口的概率密度与离散概率表示，以及四个面的通量符号。

先运行普通测试，再运行下方并行测试；普通测试的编译脚本会重建 `build/`。
网页按局部过程、组装求解和并行一致性介绍输入、参考值及实测结果。

## 串行与 OpenMP 一致性

```bash
bash tests/012_fluid/J02_neutral_sn_transport_2Drz/run_parallel.sh
```

`test_J02_parallel.f90` 通过公共入口 `sub_J02_sweep` 和
`sub_J02_solve_transport` 进行测试。非均匀 2×2 空间网格配合 16 个角方向、
3 个速率区间，覆盖开放输运、非负性、粒子收支、三种反射比例、部分入口、
无效单元和非均匀体损失；同时检查紧凑入口与完整入口的一致性、
多处错误同时出现时的确定性定位，以及迭代不收敛时不保留上一次重构场。

脚本分别编译四字节与八字节实数版本。每种精度先运行串行参考，
再用 1、2、4 个线程各运行三次，核对实际线程数，并逐字比较 17 位数字的结果记录。
记录包括分布系数、密度、两个速度分量、全部内部与边界面通量、收敛及错误状态。
只在相同精度之间比较，不要求四字节与八字节结果相同。

其余 8 个非 MPI 测试程序也分别在串行和 OpenMP 八字节版本中运行，
保留数组越界检查和浮点异常捕获。2026-10-06 的 18 组记录对照和 16 次辅助运行全部通过。
结果保存在 `build/parallel`。这些测试验证当前算例的一致性，不用于衡量加速比。

## 空间 MPI 与混合并行一致性

`test_J02_mpi.f90` 使用同一组公共入口。非均匀 5×3 空间网格配合
16 个角方向、2 个速率区间，覆盖轴线、四种迎风方向、开放和反射边界、
部分入口、进程交界面的障碍物、体损失、全无效分区及错误后的再次调用。

测试将本地分布、密度、速度、内部面、开放面和进程交界面通量，
与未分区结果核对，并检查全域收支、集体返回的错误码和全局单元位置。
仅测试驱动在各进程复制小规模参考问题，正式求解器处理本地分区。

```bash
MPIEXEC_FLAGS=--oversubscribe bash tests/012_fluid/J02_neutral_sn_transport_2Drz/run_mpi.sh
```

`--oversubscribe` 是 Open MPI 在本机可用进程槽不足时的可选参数。
编译器、启动器、启动参数与超时可分别由
`MPIFC`、`MPIEXEC`、`MPIEXEC_FLAGS`、`MPI_TEST_TIMEOUT` 设置。

脚本覆盖两种实数精度、纯 MPI、每进程 2 或 4 个线程的混合并行，
以及 1×1、2×1、1×2、2×2、3×1、1×3 六种空间分区，各重复两次。
另有四次不等宽 2×2 分区运行，径向为 4+1 单元、轴向为 2+1 单元，
并检查通信器进程编号重排。共 76 次启动于 2026-10-06 全部通过，
环境为 WSL、GNU Fortran 13.3 和 Open MPI；每次启动默认超时 90 秒。

场与通量的缩放误差上限为 `max(1e-12,100*epsilon)`，
反射迭代阈值为 `max(1e-10,8*epsilon)`，
相对粒子收支误差上限为两者较大值的 100 倍。
MPI 归约不要求在不同分区下逐位一致。
日志和构建文件位于 `build/mpi/r4` 与 `build/mpi/r8`。
