# FDTD 制造解法精度与收敛性测试

[English](README.md)

本目录通过制造解法（MMS）收敛性测试验证 Maxwell 核心内核。
测试范围不包括 CPML、粒子、电流源、碰撞或滤波。

## 测试算例

- `test_mms_3d_cartesian_convergence.f90` 用于三维直角坐标周期边界 MMS，网格为 `16^3`、`32^3`、`64^3`。
- `test_mms_2d_rz_tmz_convergence.f90` 用于二维 RZ TMz MMS，网格为 `(20,32)`、`(40,64)`、`(80,128)`。
- `test_mms_3d_cyl_m0_convergence.f90` 用于三维柱坐标 `m=0` MMS，网格为 `(20,16,32)`、`(40,16,64)`、`(80,16,128)`。
- `test_mms_2d_rz_tez_convergence.f90` 用于二维 RZ TEz MMS，网格为 `(20,32)`、`(40,64)`、`(80,128)`。
- `test_mms_3d_cyl_m1_convergence.f90` 用于三维柱坐标 `m=1` MMS，网格为 `(20,16,32)`、`(40,32,64)`、`(80,64,128)`。

## 共用设置

- 所有分辨率采用相同的 CFL 和物理结束时间 `T`。
- 使用下列正式内核。
  - `mod_E03_fdtd_3d_cartesian`
  - `mod_E01_fdtd_2d_rz_tmz`
  - `mod_E01_fdtd_2d_rz_tez`
  - `mod_E02_fdtd_3d_cylindrical`
- 精确场和源项在 `mms_exact_sources.f90` 中定义。
- 在各分量原有的交错网格位置比较精确场和数值场。
- 报告各分量和合并后的 `L2/Linf` 误差及观测收敛阶。
- RZ 和柱坐标的范数使用 `r` 加权，并报告 `axis_band_Linf`。

代码已应用以下建议通过阈值，并输出 `RESULT: PASS/FAIL`。

- `L2 observed order >= 1.8`
- `Linf observed order >= 1.5`

## 构建、运行与清理

```bash
bash make.sh
bash run.sh
bash clean.sh
```

## 最大误差位置

- 三维直角坐标的最大误差位置分布在域内多个点。
- 二维 RZ TMz 的最大误差位置在边界带内 `Ez(i=0,k=0)` 附近。
- 三维柱坐标 m=0 的最大误差位置在轴线带附近的 `Ephi(i=0,j=1,k=nz/2)` 附近。

## 统一活跃自由度后重新计算（2026-04-07）

1. 二维 RZ TMz 范数只统计实际更新的索引。
   - `Er/Ez` 的范围为 `i=0..nr-1, k=1..nz-1`。
   - 重新测得的收敛阶为 `L2 = 2.014, 2.007`、`Linf = 1.985, 1.991`，结果为 `RESULT: PASS`。

2. 三维柱坐标 m=0 的范数排除了轴线上用替代值设置的自由度。
   - 排除 `Ephi(i=0,*,*)` 和 `Hr(i=0,*,*)`。
   - 重新测得的收敛阶为 `L2 = 2.015, 2.007`、`Linf = 1.988, 1.994`，结果为 `RESULT: PASS`。

## TM 与 m=1 注意事项

- 本目录的 `m` 表示柱坐标模态展开，因此没有“三维直角坐标 m=1”算例。
- 对于二维 RZ TEz（`Ephi/Hr/Hz`），精确解采样、源项采样和误差统计范围须与更新循环一致。
- 对于三维柱坐标 `m=1`，`nphi` 须随网格细化而增加（`16 -> 32 -> 64`）。
- 轴线上的 `Ez(i=0,*,*)` 由轴线闭合项 `4*dt/(ep*dr)*axis_hphi_avg` 更新。注入源项时须跳过轴线 `Ez`。
