# G02 CSV templates

`blank/` copies the complete blank template from Tests, including headers and the prefilled manifest. Copy the whole folder and keep `tables/`. Fill it before use; the blank template is not runnable.

See the [CSV guide](../../../docs/source/tests/009_collision/G02_csv_templates.rst) for fields, units and validation commands. A [filled elastic example](../../../tests/009_collision/G02_MCC_network/data/collision_box_elastic/) uses synthetic data, unsuitable for scientific conclusions.

Keep this copy and `tests/009_collision/G02_MCC_network/templates/blank/` synchronized when changing the format.
