# J01_free_molecular

J01 的源码都放在这个目录，按用途保留两个 Fortran 模块。应用程序只需引入实际使用的模块。

## 代码分工

| 模块 | 用途 | 输入与输出 |
| --- | --- | --- |
| `mod_J01_continuity_freeflow` | 原三维连续性更新、二维给定速度通量与单步更新 | 输入密度和速度，输出通量或更新后的密度 |
| `mod_J01_neutral_free_molecular_2Drz` | 二维自由分子粒子前处理 | 输入网格、入口、壁面条件，输出参考密度、速度和面通量 |

连续性模块包含 `sub_J01_continuity_freeflow.f90` 和 `sub_J01_continuity_freeflow_2Drz.f90`。原有过程名、参数与三维索引约定不变；三维接口中的 `s` 是本步扣减量，不是每秒产生率。

粒子模块包含以下文件：

- `sub_J01_free_molecular_mc_2Drz.f90`：检查输入，组织采样和轨迹循环，返回统计结果。
- `sub_J01_fm_sampling.f90`：计算入口面积与粒子率，采样入射位置和速度。
- `sub_J01_fm_trajectory.f90`：定位单元，推进粒子至下一面，累计驻留时间和穿面次数。
- `sub_J01_fm_reflection.f90`：按壁面条件改变粒子速度。
- `sub_J01_fm_statistics.f90`：分配统计数组，将驻留和穿面计数换算为密度、平均速度和通量。

## 与 J03 连接

粒子前处理不需要已有的中性场。它由注入粒子生成参考密度及通量，应用驱动再补上同一定义下的入口通量，调用 `sub_J03_initialize_transport_closure`。J03 保存由参考场算出的面速度，随后按当前迎风密度计算通量；它不重复跟踪粒子。

具体器件几何、运行参数、结果文件和出图属于测试或应用驱动，不放入这些计算过程。

## 模型范围

当前粒子模型只含 r、z 两个速度分量，单元内轨迹为直线，不含周向运动、体内电离和分子间碰撞。入口使用截断正态的入射事件分布，并未额外按法向速度加权。它与储气池 Maxwell 通量采样不是同一个定义。

密度由粒子率乘驻留时间除以体积得到；面通量由粒子率乘有符号穿面次数除以面积得到，不能用单元平均速度乘密度替代。

## 编译和测试

仅编译所需的 `mod_*.f90`，启用预处理并将本目录加入 include 路径，不单独编译 `sub_*.f90`。两个模块保留原名称；同时使用时建议通过 `only` 指定所需过程，避免同名常量冲突。

在仓库根目录运行：

```bash
bash tests/011_fluid/J01_free_molecular/run.sh
```

该入口运行三维更新、二维通量及粒子模块测试。Sphinx 的 `J01_free_molecular` 页面给出各文件的公式、参数和测试位置。
